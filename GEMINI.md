# Gemini project instructions

Read and follow [AGENTS.md](AGENTS.md), the shared project engineering guidelines, before making changes. Read [README.md](README.md) for the five maintained guides and [development](docs/development.md) for the change and verification workflow.

All implemented connectors are in scope according to project enablement and validated configuration. Preserve read-only operations, server-derived authorization, project isolation and independent review. See [configuration](docs/configuration.md) for the connector inventory and remaining implementation gaps.

Keep project-wide rules in `AGENTS.md`; do not duplicate or weaken them here. Historical documents under `docs/reference/` are context, not current instructions.
